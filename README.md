# АндрейСпросил

## Режимы

- **Телефон** (`index.html`) — обычный сайт
- **Компьютер** (`desktop.html`) — сайт внутри розового экрана на фоновой картинке

Справа сверху две компактные группы переключателей, на любом устройстве:

- вид: 📱 / 💻
- фон: 🏙️ Урбан / 🎃 Хэллоуин / 💅 Гламурный (первый заход — Хэллоуин, дальше запоминается выбор)

Картинки фонов: `Bg/frame-*.webp` (розовый экран в них вырезан, сайт показывается под ними).
Исходные фото лежат рядом: `Bg/IMG_*.jpeg`. Если замените фото, окно сайта придётся подогнать заново.

## Выпуски

Кладите MP3 в `podcasts/НАЗВАНИЕ_ПАПКИ/`, например:
`podcasts/Интервью/2026-10-24 Тема.mp3`

Дата в начале имени необязательна. Без неё берётся дата загрузки файла.

После загрузки `catalog.json` обновляется сам: GitHub Actions запускает `make_catalog.py`
(вкладка **Actions** → «Обновить каталог выпусков»; можно запустить вручную кнопкой **Run workflow**).
Название, дату и обложку выпуска можно поправить в `catalog.json` руками, скрипт их не затрёт.

Локально: `python3 make_catalog.py`.

## Pages

Settings → Pages → Source: Deploy from a branch (main) **или** GitHub Actions.
Settings → Actions → General → Workflow permissions: **Read and write permissions**.
