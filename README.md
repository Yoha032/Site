# АндрейСпросил

Как добавить выпуск:
1. Откройте папку `podcasts` и нужную подпапку (Интервью, Подкасты, Эфиры). Новые папки = новые разделы на сайте.
2. Загрузите MP3. Имя файла: `2026-10-11 Тема выпуска.mp3` (дата в начале).
3. Через минуту-две каталог `catalog.json` обновится сам, и выпуск появится на сайте. Самый свежий по дате встанет первым.

Яндекс Метрика: в файле `index.html` найдите строку `var MID=0;` и вместо 0 впишите номер счётчика.
