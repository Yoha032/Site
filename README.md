# АндрейСпросил

Добавить выпуск: положите MP3 в `podcasts/НАЗВАНИЕ_ПАПКИ/`, имя файла `2026-10-11 Тема выпуска.mp3` (дата в начале). Папка = раздел на сайте.
Сайт собирается и публикуется сам (вкладка Actions → «Сборка и публикация сайта»). Каталог `catalog.json` создаётся во время сборки.

Настройка один раз: Settings → Pages → Build and deployment → Source: GitHub Actions.

Яндекс Метрика: в `index.html` найдите `var MID=0;` и впишите номер счётчика.
