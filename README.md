# АндрейСпросил

## Как добавить выпуск

1. Положите MP3 в папку раздела, например:
   ```
   podcasts/Интервью/2026-10-24 Джингл приглашение в Паблик Бар.mp3
   ```
2. **Лучше** начинать имя файла с даты `ГГГГ-ММ-ДД`, потом название.
   Можно и без даты в начале — скрипт попробует найти дату в названии (в т.ч. «24 октября»).
3. Закоммитьте и запушьте в ветку `main`.
4. Сайт сам пересоберётся (Actions → «Сборка и публикация сайта»).  
   Файл `catalog.json` создаётся автоматически — руками его править не нужно.

## Настройка один раз

Settings → Pages → Build and deployment → Source: **GitHub Actions**.

## Яндекс Метрика

В `index.html` найдите `var MID=0;` и впишите номер счётчика.
