# АндрейСпросил

## Режимы

- **Телефон** (`index.html`) — обычный сайт
- **Компьютер** (`desktop.html`) — сайт внутри телефона на художественном фоне

Переключатель 📱 / 💻 в правом верхнем углу.  
На компьютере: фоны **Урбан / Хэллоуин / Гламурный** (слева сверху).

## Выпуски

Кладите MP3 в `podcasts/НАЗВАНИЕ_ПАПКИ/`, например:
`podcasts/Интервью/2026-10-24 Тема.mp3`

После загрузки обновите `catalog.json` или запустите `make_catalog.py` (если есть в репозитории).

## Pages

Settings → Pages → Source: Deploy from a branch (main) **или** GitHub Actions.
