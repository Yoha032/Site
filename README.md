# АндрейСпросил

## Режимы

- **Телефон** (`index.html`) — обычный сайт
- **Компьютер** (`desktop.html`) — сайт внутри розового экрана на фоновой картинке

Справа сверху две компактные группы переключателей, на любом устройстве:

- вид: 📱 / 💻
- фон: 🏙️ Урбан / 🎃 Хэллоуин (первый заход — Хэллоуин, дальше запоминается выбор)

Картинки фонов: `Bg/frame-*.webp` (розовый экран в них вырезан, сайт показывается под ними).
Исходные фото лежат рядом: `Bg/IMG_*.jpeg`. Если замените фото, окно сайта придётся подогнать заново.

## Выпуски

Кладите MP3 в `podcasts/НАЗВАНИЕ_ПАПКИ/`, например:
`podcasts/Интервью/2026-10-24 Тема.mp3`

Дата в начале имени необязательна. Без неё берётся дата загрузки файла.

Новый MP3 появляется в плеере сам, двумя способами:

1. **Сразу, прямо в браузере.** Сайт на GitHub Pages сам смотрит список файлов в `podcasts/`
   и добавляет те, которых ещё нет в `catalog.json` (папка тоже создаётся сама).
   Название берётся из имени файла, дата: из начала имени или из даты загрузки.
   Это работает без настроек, но у GitHub есть лимит запросов (60 в час с одного IP), поэтому список кэшируется на 2 минуты.
2. **Через `catalog.json`.** GitHub Actions запускает `make_catalog.py` при каждой загрузке MP3
   (вкладка **Actions** → «Обновить каталог выпусков»; можно запустить вручную кнопкой **Run workflow**).
   Он считает длительность и фиксирует данные в каталоге. Название, дату и обложку можно поправить в `catalog.json` руками, скрипт их не затрёт.

Локально: `python3 make_catalog.py`.

## Pages

Settings → Pages → Source: Deploy from a branch (main) **или** GitHub Actions.
Settings → Actions → General → Workflow permissions: **Read and write permissions**.

## Игра «Потехе час»

Внизу страницы (`index.html`, блок `#potehe`) живёт мини-игра: пиксельный Андрей бежит от нечисти.
Прыжок: тап по игре или пробел (держите дольше, чтобы прыгнуть выше), пригнуться: кнопка или ↓.
Игра встаёт на паузу, пока её не видно на экране. Личный рекорд хранится в браузере игрока.

## Страница «Мои работы»

Открывается кликом по бегущей строке внизу главной (`media.html`).
Список работ берётся из файла `works.json`: добавляйте записи туда, код трогать не нужно.

```json
{
 "works": [
  {
   "title": "Название мероприятия: видеоотчёт",
   "type": "ev",
   "date": "2026-10-24",
   "role": "ведущий",
   "duration": "4:20",
   "url": "https://www.youtube.com/watch?v=XXXXXXXXXXX",
   "new": true
  }
 ]
}
```

- `type`: `ev` (мероприятие), `in` (интервью), `sh` (шоу). Обязательны только `title` и `type`.
- `url`: ссылка на видео. YouTube и RuTube открываются прямо в окне на сайте, ссылка на `.mp4` из репозитория тоже.
  Для ВК лучше добавить поле `embed` (ВК → «Поделиться» → «Экспортировать», берите адрес из `src`).
  Если видео не встроить, в окне будет ссылка «Открыть на сайте-источнике».
- `cover`: обложка (путь к картинке). У YouTube обложка подтягивается сама.
- `new`: `true` показывает значок «НОВОЕ». Свежие работы идут первыми (по `date`).
- Пока список пуст, на странице написано «Скоро здесь появятся работы».
  Посмотреть оформление с образцами: `media.html?demo` (нигде не ссылается, на сайте не видно).
